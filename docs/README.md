# Documentation index

The `docs/` directory contains the Milestone 1 foundation and the Milestone 2
core payroll framework delivery: requirements, architecture, tenant-aware data
model, compliance posture, API design, deployment plan and milestone mapping.
Every document targets a specific audience and can be read independently.

| # | Document | Audience | Purpose |

| 01 | [Requirements](./01-requirements.md) | BA, PO, client stakeholders | Functional and non-functional scope |
| 02 | [Architecture](./02-architecture.md) | Engineering leads | System shape, components, data flow |
| 03 | [Data model](./03-data-model.md) | Backend engineers, DBAs | Entities, relationships, schemas |
| 04 | [Security & UK GDPR](./04-security-gdpr.md) | Security, compliance, DPO | Controls, data protection, audit |
| 05 | [HMRC compliance](./05-hmrc-compliance.md) | Payroll SMEs, engineering | PAYE, NI, RTI, statutory payments |
| 06 | [API design](./06-api-design.md) | Frontend & integrator devs | REST conventions, auth, versioning |
| 07 | [Deployment & environments](./07-deployment.md) | DevOps, SRE | CI/CD, envs, observability |
| 08 | [Milestone plan](./08-milestone-plan.md) | PM, client | Milestones mapped to the SOW |
