# 06 — API design

## 1. Principles

- **REST over JSON.** Resources map to nouns. Verbs are HTTP methods.
- **Versioned URL prefix.** `/api/v1`. Breaking changes bump to `/api/v2`.
- **Stable identifiers.** UUIDs, never auto-increment integers in URLs.
- **Consistent errors.** RFC 7807 (`application/problem+json`) from M2.
- **Idempotency.** All `POST` endpoints that create resources accept an
  `Idempotency-Key` header (M2).
- **Pagination.** Cursor-based pagination for large collections (M2).
- **OpenAPI source of truth.** `/openapi.json` is generated by FastAPI and
  consumed by integration partners. Clients can be code-generated from it.

## 2. URL conventions

```
/api/v1/<collection>
/api/v1/<collection>/{id}
/api/v1/<collection>/{id}/<sub-collection>
```

- Collections are lowercase plural nouns: `/employees`, `/pay-runs`.
- Sub-collections nest only when the lifecycle is truly dependent.
- Filters live in query string: `?status=active&limit=50&cursor=...`.

## 3. Milestone 1 endpoints

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/` | Service identity banner |
| `GET` | `/api/v1/health` | Liveness |
| `GET` | `/api/v1/health/ready` | Readiness (DB reachable) |
| `GET` | `/api/v1/meta/version` | Build version |
| `GET` | `/api/v1/meta/milestone` | Current SOW milestone |
| `POST` | `/api/v1/auth/login` | Password → JWT (stub) |
| `GET` | `/api/v1/employees` | List employees |
| `POST` | `/api/v1/employees` | Create employee |
| `GET` | `/api/v1/employees/{id}` | Fetch one |

Interactive documentation at `/docs` (Swagger UI) and `/redoc`.

## 4. Authentication

Milestone 1 ships a login stub (`/auth/login`) returning access and refresh
JWTs. Middleware to enforce bearer tokens on protected routes is added in
Milestone 2 together with the RBAC model.

Headers:

```
Authorization: Bearer <access_token>
```

## 5. Errors

### Milestone 1 (FastAPI defaults)

```json
{
  "detail": "Invalid credentials"
}
```

### Milestone 2 onwards (RFC 7807)

```json
{
  "type": "https://payroll.snovasys.com/problems/invalid-ni-number",
  "title": "Invalid UK National Insurance number",
  "status": 422,
  "detail": "'123456789' does not match the required pattern.",
  "instance": "/api/v1/employees",
  "errors": [
    { "loc": ["body", "national_insurance_number"], "msg": "Invalid format" }
  ]
}
```

## 6. Versioning & deprecation policy

- Backwards-compatible changes (additive fields, new endpoints) ship inside
  the same major version.
- Breaking changes require a new major version with a 6-month overlap
  period.
- Deprecation notice is delivered via `Deprecation` + `Sunset` response
  headers (RFC 8594).

## 7. Rate limiting

- Implemented via Redis from Milestone 2.
- Default: 60 req/min per IP for anonymous, 600 req/min per authenticated
  user. Burst-friendly token bucket.

## 8. OpenAPI contract testing

- CI verifies the committed `openapi.json` matches what FastAPI emits.
- Frontend types are generated from OpenAPI in Milestone 2 and committed.
