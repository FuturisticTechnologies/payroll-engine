# Engineering handbook

`docs/01` through `docs/09` are **milestone deliverables** - they are written
once, reviewed with the client, and signed off. They describe what the platform
is contracted to do.

This folder is the other kind of document: **living operational reference**
maintained by the engineering team. It is not part of the SOW, it has no
sign-off, and it is expected to change whenever the practice it describes
changes.

| Document | Owner | Added |
|---|---|---|
| [Developer workflow](./developer-workflow.md) | DevOps | M1 |
| [Data dictionary](./data-dictionary.md) | Data Analyst | M2 |
| [Reconciliation export](./reconciliation-export.md) | Data Analyst | M3 |
| [Statutory payment reference data](./statutory-reference-data.md) | Data Analyst | M8 |

Add a row when you add a document. If a handbook page and a numbered
deliverable disagree, the deliverable is the contract and the handbook is
wrong.
